# 2026년 다이어리 기록 모음.zip 🎀

파스텔 핑크 테마의 Streamlit 다꾸 작품 아카이브.

## 실행 방법
1. Python 설치
2. 터미널에서 프로젝트 폴더로 이동
3. 아래 명령어 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 작품 등록
앱 상단의 `＋ 새로운 작품 등록하기`를 열고 제목, 날짜, 카테고리, 설명, 사진을 입력한 뒤 등록하세요.

작품 데이터와 업로드 사진은 `gallery_data/` 폴더에 저장됩니다.
배포 플랫폼에 따라 파일 저장이 유지되지 않을 수 있으므로 공개 운영 시 영구 저장소 연결을 권장합니다.
